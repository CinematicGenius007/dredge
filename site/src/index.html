    dredge v0.2.0 · where did your disk go?

    A read-only disk explorer for macOS, Linux and Windows. It reads your disk once, saves a snapshot,
    and answers in one screen: what is big, what rebuilds itself, and the command to clear it.
    It never deletes anything. It also runs as an MCP server for Claude and other agents.

    cargo install --git https://github.com/CinematicGenius007/dredge dredge-cli

    Commands. Click one, or type it below.

    • tutorialsix steps from install to MCP, about two minutes
    • demoread a folder of yours in this tab; nothing is uploaded
    • mcpadd dredge to Claude Code, Claude Desktop, Cursor or any MCP client
    • ruleswhat dredge will and will never do
    • helpeverything else this shell understands
